NOVA – The Hero Who Listens 🦸‍♀️

NOVA is an interactive Superhero Help Portal designed around the idea that every person deserves to be heard.

NOVA is a fictional superhero with the power to sense when someone needs help through a mysterious Hope Signal. Instead of fighting villains, NOVA listens to people's problems, understands their concerns, and guides them toward hope and support.

✨ Features

- 🦸‍♀️ Original female superhero character – NOVA
- 🌌 Futuristic cosmic/neon visual design
- 📖 NOVA's origin story, powers, mission, and personality
- 💬 Interactive conversational chatbot
- 📝 Collects visitor name, age, location, email, and request
- 📧 Automatic email notification using EmailJS
- 📱 Responsive design for desktop and mobile
- ✨ Animated effects, glowing UI, and smooth navigation
- 🔗 Interactive navigation and “Ask NOVA” call-to-action

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS
- GitHub

🎯 Project Mission

«“No problem should go unheard.”»

NOVA represents the idea that sometimes people don't need a hero who fights — they need a hero who listens.
